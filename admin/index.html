관리자 기능 연결 안내

게시판·갤러리·문의·후원 신청·방문 통계를 관리하려면 데이터베이스(Supabase)를 한 번 연결해야 합니다.

  1. supabase.com에서 새 프로젝트를 만듭니다. (지역: Northeast Asia (Seoul) 권장)
  2. 프로젝트의 SQL Editor에 저장소의 supabase/schema.sql 내용을 붙여 넣고 실행합니다.
  3. Authentication → Users에서 관리자 계정(이메일/비밀번호)을 만들고, schema.sql 맨 아래 ‘관리자 등록’ 쿼리를 이메일만 바꿔 실행합니다.
  4. Authentication → Sign In / Providers에서 ‘Allow new users to sign up’을 꺼 둡니다. (관리자 외 가입 차단)
  5. Project Settings → API의 Project URL과 anon public key를 assets/js/config.js의 supabase.url, supabase.anonKey에 입력합니다.

연결 전까지 홈페이지는 data/*.json 파일의 내용으로 표시되며, 문의·신청은 메일 앱으로 접수됩니다.
