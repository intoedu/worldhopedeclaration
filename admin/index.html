관리자 기능 설정 안내

관리자 화면은 홈페이지 파일이 있는 GitHub 저장소를 직접 수정합니다. assets/js/config.js 의 github.owner(저장소 소유자), github.repo(저장소 이름), github.branch(보통 main)를 입력한 뒤 다시 열어 주세요.

관리자 로그인

GitHub 토큰(개인 액세스 토큰)으로 로그인합니다. 토큰이 없다면 아래 ‘토큰 만드는 방법’을 먼저 따라 해 주세요.

체크하지 않으면 이 브라우저 탭을 닫을 때 로그인 정보가 지워집니다. 여러 사람이 함께 쓰는 컴퓨터에서는 체크하지 마세요.

토큰 만드는 방법 (처음 한 번, 약 3분)
  1. 저장소 에 쓰기 권한이 있는 계정으로 GitHub에 로그인합니다.
  2. 오른쪽 위 프로필 사진 → Settings → 왼쪽 메뉴 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
    (바로가기: github.com/settings/personal-access-tokens/new)
  3. Token name: 알아보기 쉬운 이름 (예: 홈페이지 관리자) · Resource owner:
  4. Expiration: 사용 기간을 정합니다 (예: 90일). 만료되면 같은 방법으로 새로 만들어 다시 로그인하면 됩니다.
  5. Repository access: Only select repositories → 선택
  6. Repository permissions → Contents: Read and write (Metadata: Read-only 는 자동으로 선택됩니다)
  7. Generate token을 누르고, 화면에 한 번만 보이는 토큰(github_pat_…)을 복사해 위 칸에 붙여 넣습니다.

토큰은 비밀번호와 같습니다. 다른 사람에게 보내지 말고, 잃어버렸거나 유출이 의심되면 같은 화면(Fine-grained tokens)에서 바로 삭제(Delete)하세요. 토큰은 이 브라우저에만 저장되며 GitHub(api.github.com) 외의 곳으로는 전송되지 않습니다. 단체(Organization) 저장소라면 조직 관리자의 토큰 승인이 필요할 수 있습니다.
