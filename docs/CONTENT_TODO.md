# 자료 요청 · 확인 체크리스트

시안은 의뢰서와 보내주신 취지문·인사말을 기준으로 만들었습니다. 아래 항목을 받거나 확정하면 바로 반영합니다.

## 1. 받아야 할 자료

| # | 자료 | 반영 위치 | 비고 |
|---|---|---|---|
| 1 | 로고 원본 (SVG·AI 권장, 없으면 투명 배경 고해상도 PNG) | 헤더·푸터·QR 가운데·파비콘·공유 이미지 | 현재는 임시 로고(지평선 위 새벽빛) |
| 2 | 대표자(원치현 위원장) 사진 — 세로형 4:5 | 소개·인사말 | |
| 3 | 활동 사진 (행사·사역 현장·선언 관련) | 갤러리, 홈 미리보기 | 앨범 구분 함께 주시면 좋습니다 |
| 4 | 참고 사이트 (카톡으로 보내신 것) | 디자인 조정 | 아직 받지 못한 상태로 제작 |
| 5 | 도메인 주소 (카톡으로 보내신 것) | `scripts/set-domain.mjs` 실행 | QR코드 최종 주소가 이 값으로 고정됩니다 |

## 3. 제작 중 추가·판단한 사항 (유지 여부 확인)

- **희망 응원 메시지** (홈): 의뢰서의 ‘바라는 행동: 참여 및 응원’을 반영해 추가. 관리자 승인 후 게시
- **성경 구절**: 홈 로마서 15:13, 후원 고린도후서 9:7 (국문 개역개정 / 영문 KJV)
- **참여·동역 신청**: 별도 메뉴 대신 ‘문의하기’의 문의 유형으로 통합
- **정기 후원 신청서**: 계좌번호·주민등록번호는 온라인으로 받지 않고 담당자가 전화로 안내하는 방식

## 4. 원문 교정 내역 (보내주신 글)

- “셰계희망연대” → “세계희망연대”
- “더 나가가” → “더 나아가”
- “지금같은” → “지금 같은” (띄어쓰기)
- 그 밖의 표현(‘홈사이트’, ‘나침판’ 등)은 원문 그대로 두었습니다.

## 5. 기술 연결 (오픈 전)
