## 5. 기술 연결 (오픈 전)

서버·데이터베이스 없이 GitHub Pages + 이메일로 운영합니다. 자세한 방법은 `README.md` 참고.

- [ ] GitHub Pages 켜기 — 저장소 Settings → Pages → Deploy from a branch / `main` / `(root)` → https://intoedu.github.io/worldhopedeclaration/ 접속 확인
- [ ] **이메일 접수 활성화(FormSubmit)** — 게시 후 문의 폼에서 시험 접수 1건 → `config.js` 의 `email.to` 수신함에 온 확인 메일에서 **Activate** 클릭 → 다시 시험 접수해 메일 도착 확인 (스팸함 확인). 문의·정기 후원 신청·응원 메시지 폼을 각각 한 번씩 시험
- [ ] (권장) 활성화 메일의 별칭 문자열을 `email.to` 에 넣어 주소 숨기기 + `publicEmail` 입력(메일 앱 대체 경로용)
- [ ] **관리자용 GitHub 토큰** — 관리자마다 Fine-grained token 발급(이 저장소만, Contents: Read and write, 만료일 지정) → `/admin/` 로그인·글 1건 등록 시험
- [ ] PG 가맹(PortOne) → `config.js` 의 `portone.storeId`, `portone.channelKey` 입력 → 소액 시험 결제 → PortOne 콘솔 내역과 알림 메일 대조
- [ ] (선택) GoatCounter 계정·사이트 코드 → `analytics.goatcounter` (하단 누적 방문자: GoatCounter 설정의 ‘Allow adding visitor counts’ 켜기)
- [ ] (선택) Google Analytics 4 측정 ID → `analytics.ga4`
- [ ] 개인정보처리방침의 위탁·국외 이전(제5조), 자동 수집(제9조)을 실제 사용하는 서비스에 맞춰 확정
- [ ] 게시 철회·삭제 요청 시 변경 이력까지 정리할 담당자(Git 사용 가능) 지정 — 절차는 `README.md` ‘게시 철회·삭제 요청 처리’
- [ ] 공식 주소 반영 `node scripts/set-domain.mjs https://intoedu.github.io/worldhopedeclaration` (도메인을 쓰면 아래 항목으로)
- [ ] (도메인 사용 시) `README.md` ‘연결 도메인’ 순서대로: 도메인 소유 확인(TXT) → DNS 등록(A 레코드 185.199.108.153 / 109.153 / 110.153 / 111.153, `www` CNAME → `intoedu.github.io`) → Settings → Pages → Custom domain 에 `www.도메인` 저장 → `node scripts/set-domain.mjs https://www.도메인` 커밋 → **Enforce HTTPS** → 새 주소에서 이메일 접수 다시 시험(FormSubmit 재활성화) → 관리자 재로그인 → QR 인쇄물 새로 만들기
- [ ] `config.js` 의 `draft: false` 로 변경 → 시안 안내 바 제거

## 7. 공개 전 의뢰인 확인 (디자인 개편 점검에서 나온 것)
- [ ] **목표 국가 수(위 6번 마지막 줄)** — 홈 ‘함께하는 나라들’ 구역에 큰 공식(33 × 195 = 6,435)으로 보이므로 공개 전에 195/210 중 하나로 확정. 확정 전까지 공식 아래 설명에 ‘(목표치)’를 붙여 둠
- [ ] **‘홈페이지 이용 안내’ 공지(data/posts.json `site-guide`) 문구 수정** — 홈 소식 카드에 보이는 글인데, 지금 화면과 맞지 않는 두 문장이 있음 (관리자 화면에서 수정 · 승인 전까지 그대로 둠)
  - 2번 지금: “맨 위의 ‘QR코드’ 버튼을 누르면 …” → 데스크톱 맨 위에는 QR 버튼이 없음(휴대폰은 전체 메뉴 아래쪽, 데스크톱은 검색 창 안). 제안: “QR코드 — 휴대폰은 전체 메뉴(☰) 아래쪽, 컴퓨터는 맨 위 검색(돋보기) 창에서 지금 보고 계신 페이지의 QR코드를 볼 수 있습니다. ‘QR코드’ 페이지에서는 …(뒷부분 그대로)”
  - 4번 지금: “‘후원·헌금’ 메뉴에서 후원 방법을 확인하실 수 있습니다.” → 후원 페이지는 ‘계좌 안내 준비 중’ 안내만 보임. 제안: “후원·헌금 — 후원 계좌와 온라인 후원 방법은 확정되는 대로 ‘후원·헌금’ 페이지에 안내해 드립니다.”
- [ ] **위원장 사진 홈 사용** — 소개 페이지용으로 받은 사진(“대표사진 이걸로 해줘”)을 홈 인사말 구역에도 크게 씀. 홈 사용도 괜찮은지 확인 (안 되면 사진 없이 서명만)
- [ ] **공유 제목(og:title)** — 페이지 제목(브라우저 탭)은 ‘세계희망선언문 — 5대 원칙과 5대 가치’처럼 자세히 바꿨지만, 카카오톡 등 공유 미리보기 제목(og:title)은 도메인 연결 때 정한 값 그대로 둠. 공유 제목도 자세히 바꿀지 결정
- [ ] **후원 버튼** — 계좌·결제가 준비되기 전에는 비전과 미션 맺음 띠의 ‘후원하기’ 버튼 대신 ‘글로벌 대표 추천하기’를 보여 줌(준비되면 config.js 값만 넣으면 자동으로 ‘후원하기’로 돌아옴). 사이트 검색 결과의 후원 설명도 같은 기준
- [ ] (참고) 휴대폰 홈은 길이를 줄이려고 원칙 풀이 글·추천 절차 4단계·연락처 띠(푸터와 같은 내용)·인사말 둘째 문단을 숨기고, 각 줄을 누르면 해당 페이지에서 전문을 보도록 함
